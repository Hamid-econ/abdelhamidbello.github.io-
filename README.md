# Abdel-Hamid Bello — Academic Website

Academic website for Abdel-Hamid Bello, built as a lightweight static site for GitHub Pages.

## Pages

- `index.html` — homepage
- `research.html` — publications, working papers, and work in progress
- `teaching.html` — teaching experience
- `contact.html` — contact and academic profile
- `assets/style.css` — site design
- `assets/main.js` — mobile navigation and footer year

## GitHub Pages

This repository is intended to be published from the `main` branch and repository root using GitHub Pages.

## CV

The navigation expects the CV at `files/Abdel-Hamid-Bello-CV.pdf`. Upload the current CV using that exact path and filename.

## Custom domain

After the GitHub Pages preview is approved, the site can be connected to `www.abdelhamidbello.com` with a `CNAME` file and the appropriate DNS settings. Keep the existing site active until the new domain configuration is confirmed working.
